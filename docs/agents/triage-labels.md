# Triage Labels

The skills speak in terms of five canonical triage roles. The table below maps each role to the GitHub Issue label used by this repository.

| Label in mattpocock/skills | Label in baigei-bubaigei/cangkuguanli | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions one of these roles, apply the corresponding GitHub label from the right-hand column.
